# LUMIÈRE

LUMIÈRE is a luxury lifestyle and e-commerce landing page inspired by refined editorial design. The name is derived from the French word for "light," symbolizing elegance, warmth, and curated living. This project presents a premium shopping experience for fashion, accessories, and home objects through a clean, immersive, and visually rich storefront.

## Overview

This project is a creative e-commerce web design concept built as a single-page storefront experience. It focuses on premium branding, editorial storytelling, product discovery, and a minimalist luxury aesthetic.

The interface is designed to feel like a modern luxury brand website, combining:

- a cinematic hero section
- boutique-style product browsing
- category filters and search
- interactive wishlist buttons
- cart count feedback
- elegant typography and a warm neutral palette

## Key Features

- Luxury editorial visual style with warm cream, charcoal, and copper tones
- Full-width hero section with premium brand messaging
- Marquee-style brand promotion strip
- Product catalog with category pills and sorting controls
- Live search filtering for product discovery
- Hover animations and product image transitions
- Wishlist interactions for customer engagement
- Cart badge updates and toast notifications for feedback
- Responsive layout for desktop and mobile screens

## Design Philosophy

LUMIÈRE is designed to evoke the feeling of a curated lifestyle brand. Rather than a standard online retailer, the interface tells a story of elevated living—where fashion, home accents, and personal expression come together in a carefully considered collection.

The visual language uses:

- serif typography for a premium editorial tone
- soft neutral color palette for sophistication
- subtle motion and hover effects for modern elegance
- spacious layout to highlight product presence and brand atmosphere

## Getting Started

Since this is a static front-end project, you can run it in two simple ways:

### Option 1: Open directly in a browser

- Download or clone the repository.
- Open `index.html` in your browser.

### Option 2: Use a local web server

```bash
cd LUMIERE
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Usage

The page is meant to function like a luxury storefront landing experience. Visitors can:

- explore the featured editorial hero
- browse curated product cards
- filter items by category
- search for products by name
- save products to a wishlist
- add items to a cart and receive visual feedback
